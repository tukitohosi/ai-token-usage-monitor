# v0.10.0 升级说明

v0.10.0 新增定价 JSON 迁移和桌面宠物浮窗，方便在本机备份模型价格、迁移宠物资源，并随时查看今天的本机用量与 Codex 套餐额度。

## 模型定价 JSON 导入与导出

模型定价页支持导出已保存价格和导入 JSON 文件。

- 导出包含整套已保存的模型价格与高峰计费规则。尚未保存的编辑草稿不包含在导出中。
- 文件格式为 “ai-token-pricing” v1，单价单位为 “perMillionTokens”（每百万 Token）。
- 按 modelId 忽略大小写合并。文件中已有相同 ID 时，以导入的模型价格覆盖当前对应模型；本地没有出现在文件中的模型保留。显示名称相同但 ID 不同的模型按独立 ID 处理，避免把价格套到另一个模型。
- 导入结果先进入编辑草稿。检查导入摘要后，点击“保存价格并重算”才会应用。
- 默认保留本地高峰规则和已存在模型的高峰开关。勾选“同时导入高峰规则”后，文件中的高峰时段、倍率、时区、特殊日期和导入模型的高峰开关会替换对应本地设置。高峰规则为共用配置，替换后也会影响其他启用高峰计费的模型。
- null 表示该单价未定价；0 表示零价格。文件大小上限为 1 MiB，最多 200 个模型；若合并结果超出上限，整个导入不会应用。

## 桌面宠物与用量条

桌面宠物设置支持显示开关、拖动位置、调整大小和选择主题。可扫描本机 Codex 自定义宠物目录、选择其他 Codex 目录，或手动导入 pet.json、PNG 和 WebP 动画图集。支持 v1、v2 图集；导入资源复制到应用自己的目录，之后无需启动 Codex。

云端资源如果只提供宠物 ID，需要先在本机保存，再导入到应用。应用不包含 Codex 官方内置宠物。

宠物下面的用量条从本应用共用数据中显示：

- 今日全部来源的 Token 总量，以及按币种分别计算的 API 费用估算。
- Codex 5 小时、7 天和储备额度的剩余比例及重置时间。
- 旧额度会标为旧数据并显示更新时间。若额度记录中的重置时间已过，显示等待更新，不表示额度已经恢复。
- 不显示 Token/秒速率。

关闭主窗口时，应用默认留在系统托盘，桌面宠物继续运行；从托盘选择“退出”会同时结束应用和宠物。宠物窗口外围的透明区域可点击穿过，不会夺取其他窗口焦点。

## 下载与升级

在 [v0.10.0 发布页](https://github.com/tukitohosi/ai-token-usage-monitor/releases/tag/v0.10.0) 下载 AI-Token-Usage-Monitor-0.10.0-Setup.exe，适用于 Windows x64。已有版本可直接覆盖安装。

费用按应用里已保存的模型价格估算，不等于服务商账单；USD 和 CNY 分别显示。Codex 账号额度需要联网同步。

## 验证范围

- 前端 22 个测试文件、186 项测试通过；npm run typecheck 通过。
- Rust 回归测试 119 项通过、0 项失败、3 项忽略；之后的宠物 IPC 修改通过 cargo check --locked。
- Windows 界面已验证本机 Codex 宠物列表与预览、宠物资源复制导入、开启显示及重启后保留；定价 JSON 原生文件选择、合并摘要（0 新增、1 覆盖、合并后 24 个）、导入草稿、保存并重算，以及宠物费用同步均已走通。隐藏主窗口到托盘后，宠物保持显示并继续刷新数据。
- 系统窗口样式读取确认宠物浮窗保持置顶、不激活前台窗口；窗口区域仅覆盖宠物和用量条，外围透明区域可点击穿过。
- 当前只有一台显示器，跨屏位置尚未验证；完整的手工拖动与焦点行为验收尚未完成。
