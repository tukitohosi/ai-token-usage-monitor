# v1.0.0 升级说明

v1.0.0 集中完善了桌面宠物、后台刷新提示和 WorkBuddy AI 本机用量采集。可从 [GitHub v1.0.0 发布页](https://github.com/tukitohosi/ai-token-usage-monitor/releases/tag/v1.0.0) 下载 Windows x64 安装包或源码压缩包；已有版本可直接覆盖安装。

## 桌面宠物与倒计时

- 用量条后台倒计时现在显示“约 XX 秒后自动更新”，并与本机扫描进度、账号同步及旧数据提示同步。若账号数据晚于本机扫描返回，提示会等本轮工作结束后再继续倒数，不会为了倒计时额外刷新。
- 内置完整 v2 透明狐仙地灵宠物。悬停显示 waiting 动作；宠物按屏幕移动方向左右奔跑并在方向变化时换向，松开后恢复常规动作状态。
- 宠物时序与本机 Codex 的逐帧节奏对齐，待机约 6.6 秒；临时动作播放三轮后回到待机。
- 宠物窗口显示和拖动期间保持置顶但不激活，因此不会抢占当前应用焦点。外围透明区域可点击穿过。

## WorkBuddy AI 用量修复

- 扫描 projects 下的会话 JSONL；会话仍在运行时，已写入磁盘的调用即可统计。不完整尾行会在后续扫描时继续读取。
- 修正稳定调用去重、流式快照替换、缓存和输出分类，以及零值占位处理。
- 综合 trace 汇总与逐次调用记录，优先保留较完整的信息且不重复累计；如果记录只存在于一个来源，则继续保留这段历史。
- 升级后自动重新解析 WorkBuddy 记录并补回遗漏，其它来源历史保留。

## 验证结果

- 前端 23 个测试文件、196 项测试通过；类型检查和前端构建通过。
- Rust 测试 126 项通过、0 项失败、3 项可选环境测试忽略。
- Windows Win32 隐藏窗口置顶与不激活测试通过。
- 本机匿名对账通过：现存来源记录与保留历史均逐条匹配。对账结果只用于验证，没有公开个人 Token 数量。
