# v1.0.1 — 2026-11-11

本次修复桌面宠物启动时的白条、贴近屏幕边缘时的回弹和用量条越界，以及账号额度刷新卡住、重置到期后仍显示旧值的问题。

## 宠物窗口与屏幕边缘

- 宠物窗口在布局就绪后显示，移除启动时的标题栏白条及其多余命中区域。
- 宠物与用量条分别按屏幕工作区限制位置。宠物可以贴边停留，用量条向屏幕内侧调整；底部空间不足时，用量条自动移到宠物上方。
- 保持宠物窗口置顶且不激活，不抢走当前应用焦点。

## 账号额度刷新

- 账号额度独立刷新，并在额度重置到期时重新同步。
- 卡住的账号任务会取消并重试；界面漏收更新事件时，会重新读取当前缓存，减少一直停留在旧额度的情况。
- 到期但尚未同步成功的额度显示“待更新”，不会仅因重置时间已过就显示为 100%。
