# AI Token 用量监控

简体中文 | [English](README.en.md)

在 Windows 上查看 AI 工具的 Token 用量、模型分布和估算费用，同时查看 Codex 账号剩余额度。支持 Codex、Claude Code、OpenCode、WorkBuddy 和 WorkBuddy AI 的本机记录。

当前发布版本为 **v1.1.0**。[下载安装包](https://github.com/tukitohosi/ai-token-usage-monitor/releases/tag/v1.1.0) · [源码压缩包](https://github.com/tukitohosi/ai-token-usage-monitor/releases/download/v1.1.0/AI-Token-Usage-Monitor-1.1.0-Source.zip) · [使用指南](项目介绍与使用指南.md) · [v1.1.0 升级说明](docs/v1.1.0-升级说明.md)

v1.1.0 修复长请求沿用基础价、导致 API 费用估算偏低的问题。应用按每次请求的实际输入判断加价，同一工作区内的多个短对话各自计价。可手填规则，也可导入本机 Claude Code 状态栏正在使用的门槛与倍率。

## 主要功能

- 按日期、AI 来源、模型和项目查看用量，展开每日明细。
- 读取 Codex 普通、Zstandard 压缩与归档日志；已采集的历史不会因源文件移动或消失而自动减少。
- Claude Code 按回复合并流式用量快照，避免同一回复重复累计；该规则也适用于通过 Claude Code 调用的其他模型。
- 补读可核实的 Codex 桌面记录，并显示本机记录与账号可见的 Work 用量范围。
- 查看每日趋势和过去 24 小时活动，快速找到用量较高的模型与项目。
- 本机统计与账号额度分别刷新；账号响应慢或失败时，本机统计仍可更新。
- 自行填写模型价格，分别设置新输入、缓存读入、缓存写入和输出单价；为选定模型设置高峰时段、倍率、时区和特殊日期。
- 在「模型定价」中可为每个模型启用长上下文加价，手填门槛与倍率，或从本机 Claude Code 状态栏导入规则。点击「保存价格并重算」后，单次请求的普通输入、缓存读取与缓存写入之和超过门槛时，整次请求使用相应的输入和输出倍率。无法确认档位的历史记录按基础档估算，并显示「长上下文档位未确认」。
- 在模型定价页导出或导入 JSON。导出包含已保存的模型价格、高峰规则和长上下文规则；导入按忽略大小写的 modelId 合并到草稿，确认后再保存并重算。
- 模型定价按所有来源的累计 Token 用量从高到低排列；刷新和重新打开应用时自动核对。输入价格时保持行位置，离开输入框后更新顺序，未保存内容不会被刷新清空。
- 在“本机活动”和“费用”中导出模型用量、每日趋势、模型每日用量、应用来源和项目用量，支持 CSV、JSON 及包含全部数据的完整 JSON。
- 导出范围独立于当前页面，可选择今天、近 7 天、近 30 天、全部历史或自定义日期，并选择应用来源。同一份报表可反复导出，重新生成时才更新数据。
- 从本机 Codex 导入自定义桌面宠物，或手动导入宠物文件；调整宠物位置、大小和主题。
- 内置完整 v2 透明狐仙地灵桌面宠物：悬停时展示 waiting 动作，并根据窗口移动方向左右奔跑、换向；松开后恢复常规动作状态。
- 桌面宠物下方可查看今日全部来源 Token、按币种分别计算的 API 费用估算，以及 Codex 5 小时、7 天和储备额度的剩余比例与重置时间。后台倒计时会显示“约 XX 秒后自动更新”，并与本机扫描进度、账号同步和旧数据提示保持一致，不额外发起刷新请求。
- 宠物窗口显示、移动和拖动时保持置顶且不激活窗口，不会抢走当前应用焦点；外围透明区域可点击穿过。
- WorkBuddy AI 用量会扫描 projects 会话记录，支持读取运行中已落盘的调用、补读不完整日志尾行，并修复调用去重、流式快照、缓存和输出分类；升级后自动重新解析 WorkBuddy 记录并补回遗漏，其它来源历史保留。
- 支持纯本地模式、主题切换、系统托盘与用量提醒。隐藏主窗口到托盘后宠物会继续运行；从托盘退出应用会同时结束宠物。

## 安装与使用

正式 Setup.exe 安装包包含 WebView2 完整离线安装器；电脑缺少运行环境时自动补齐，无需自行安装 Node.js、Rust 或 Python。本机用量依赖对应 AI 软件生成的日志；Codex 账号额度仍需本机安装并登录 Codex、联网同步。

1. 在 [v1.1.0 发布页](https://github.com/tukitohosi/ai-token-usage-monitor/releases/tag/v1.1.0) 下载 AI-Token-Usage-Monitor-1.1.0-Setup.exe 并安装。
2. 首次启动等待本机记录扫描完成；历史较多时可能需要几十秒。
3. 在“本机活动”查看用量，在“模型定价”填写或导入价格，在“费用”查看估算结果。
4. 在“桌面宠物”设置中开启内置狐仙地灵，或导入本机自定义宠物。宠物窗口外围的透明区域可点击穿过，拖动时窗口保持置顶且不抢占其他窗口焦点。
5. 只需要本机统计时，在设置中开启“纯本地模式”。
6. 关闭主窗口默认收起到托盘；从托盘选择“退出”才能结束应用和桌面宠物。

## 数据与使用限制

- 本机统计包含本机已采集历史和当前能够读取的记录，不包含其他设备和云端任务的完整历史。
- Codex 账号额度需要联网获取，无法直接换算成固定的剩余 Token 数。接口没有提供的套餐续费日可自行记录。
- 费用按你填写的价格估算，不等于服务商账单；USD 与 CNY 分别统计。
- 定价文件使用每百万 Token 单价；null 表示未定价，0 表示免费。导入限制为 1 MiB、最多 200 个模型。仅按 modelId（忽略大小写）匹配，避免只用显示名称导致同名模型错用价格。
- 可导入本机的自定义 Codex 宠物或符合格式的宠物文件。Codex 云端资源若只有 ID，需要先在本机保存资源再导入；应用不包含 Codex 官方内置宠物。
- Cursor 暂无接入的数据来源，不计入本机用量。
- 内置中国大陆节假日日期覆盖 2024—2026 年；其他年份可通过特殊日期补充。
- 统计库不保存访问令牌、提示词、回答正文或工具输出。报表导出包含汇总信息，不包含账号凭据、原始对话、完整路径或会话标识。

设置和派生索引保存在当前 Windows 用户的应用数据目录。索引升级和维护会先备份应用自己的索引；重建会保留历史再重扫，不改写 AI 工具的原始记录。

需要 Node.js 22.15 或更新版本、Rust 和 Windows 构建环境。

~~~powershell
npm install
npm run desktop:dev
~~~
