# AI Token 用量监控

简体中文 | [English](README.en.md)

> 简明安装与使用说明见 [项目介绍与使用指南](项目介绍与使用指南.md)。

一个面向 Windows 的本地优先 AI Token 活动工具。它把两类数据明确分开：

- Codex App Server 返回的账号级额度与每日 Token 活动；
- 本机 Codex、Claude Code、OpenCode、WorkBuddy 与 WorkBuddy AI 的派生 Token 活动。

“本机 AI Token 活动”只描述当前电脑可读取到的历史记录，绝不是套餐额度、Credits 或账号在所有设备上的总用量。来源级 Credits 只会在将来单独显示，永不混入 Token 总量。

## 当前阶段（v0.9.2 来源筛选与空状态体验修复）

第二阶段桌面化已经落地：Tauri 2 原生壳、Rust App Server 桥、SQLite 增量索引、后台刷新、系统托盘、可选开机启动、进程单实例和 NSIS 离线安装包均已接通。当前代码优先保证：

1. 不读取 `auth.json`，不接触 ChatGPT access token；
2. 不调用未公开的 ChatGPT 后端接口；
3. 不持久化提示词、回答正文、工具输出或原始 App Server 响应；
4. 动态处理限额 bucket、未知时长、可空 credits 和 Codex 版本变化；
5. 正确处理 Codex 累计 Token 快照及子代理复制父历史造成的重复；Claude Code 按会话和消息 UUID 去重，OpenCode 按 `part.id` 去重，WorkBuddy 两套应用按 trace 稳定键去重；
6. 服务端额度卡突出“剩余”，已使用量仅作为辅助信息；
7. 官方接口未提供套餐续费日时明确显示“未提供”，也支持用户手动设置、修改和清除本机续费时间；
8. 手动续费时间只保存在应用数据目录的本地 SQLite 设置库，并标注“手动设置 · 仅本机”；
9. 多来源索引与 v1 Codex 索引完全分离：新建 `usage-index-v2.sqlite3`，不删除或迁移原有 v1；
10. Cursor 固定显示为“等待官方个人数据来源”，不读取密钥、账号状态或未公开接口；
11. 总览、本机活动、费用和设置拆分为四个紧凑视图，统一使用今日、7 天、30 天和累计筛选；
12. 支持来源多选、每日趋势、费用定价覆盖率、脱敏 CSV/JSON 导出与来源健康中心；健康中心会显示最后成功索引、本轮新增及明确解析/读取失败的跳过记录；
13. 主题可在跟随系统、浅色和深色之间恢复切换；刷新频率、关闭行为、阈值和安静时段持久化到本机设置库；
14. 日明细抽屉支持 Esc、焦点循环、关闭后焦点恢复和背景滚动锁定；
15. 首次扫描与后台刷新会显示当前来源和逐文件进度；额度剩余及低缓存任务支持严格阈值、跨午夜免打扰和条件去重的 Windows 系统通知；
16. v0.6 增加系统通知总开关、测试通知及最近成功触发记录，并在设置页显示刷新阶段耗时和脱敏数据库占用；
17. 本机活动增加基于最近 30 天日汇总的趋势、异常和置信度信号；这些信号只解释本机历史，不预测额度或账单；
18. 设置页支持只读索引自检，以及经过二次确认的“备份后重建”。维护备份只包含应用派生 SQLite 数据库及 WAL/SHM，不包含原始会话日志、设置库、完整路径或凭据。
19. v0.7 总览固定显示连续 15 个本地自然日，并按 Codex、Claude Code、OpenCode、WorkBuddy、WorkBuddy AI、Cursor 的本机可归因 Token 占比堆叠；图表紧凑数值只使用万和亿。
20. “今日”视图的小时图使用真实滚动 24 小时范围，可跨午夜显示昨天时段；零 Token 小时保留位置但不绘制柱体。
21. 顶部倒计时直接使用后台刷新截止时间；刷新完成或修改 1/5/15 分钟周期后，后台统一重置并推送新计划。
22. 关闭窗口默认直接隐藏到系统托盘且不再弹出说明；索引维护操作在设置卡片右侧对齐。
23. v0.8 修复窄窗口趋势提示导致的横向溢出，并为纯图标导航保留完整的无障碍名称。
24. 来源筛选支持真正的多选；活动与费用继续保留各自独立的来源选择。
25. 自定义日期支持连续 31 天，通过现有日期明细命令重新汇总 Token、费用、模型和项目，不使用比例推算。
26. 模型与项目排行榜支持归因下钻；趋势洞察可直接打开峰值日构成。
27. 费用页区分暂无数据、不可用、未定价和确认零费用，并增加离线价格快照与逐模型匹配说明。
28. 运行设置使用明确草稿状态；离开设置页时可选择保存并离开、放弃更改或继续编辑。
29. v0.9 总览恢复“Codex 账号近期每日 Token”服务端图表，并与“本机近 15 日 Token”明确分开展示；前者可包含其他设备和云端任务，后者只包含当前电脑可归因事件。
30. 本机活动与费用各自增加单选/多选合并开关；切回单选时保留最近选择的一个来源，两页的模式与选择互不影响。
31. AI 来源按钮使用与 15 日堆叠图一致的固定来源颜色，同时保留独立的数据源健康状态点。
32. 过去 24 小时图按来源颜色堆叠；零 Token 小时仍占位，每组三个小时只隐藏中间时刻，其余两个显示 24 小时时间。
33. 低缓存命中阈值只用于日明细标红和通知，不会从 Token 汇总、趋势或费用估算中排除任务。
34. v0.9.1 将账号日图、本机日期/小时趋势以及模型/项目用量条统一到固定 AI 来源色；24 小时图显示偶数整点并保留滚动窗口首尾。
35. 项目合并规则可跨 AI 来源持久化，只写入应用自有设置库；排行榜、项目下钻和日项目汇总应用规则，原始日志、派生索引及任务原名不变。
36. v0.9.2 修复模型/项目空状态文字容器被旧样式压缩而越界的问题；AI 来源改用明确的单选/多选分段控件，并以红色描边和勾号突出当前选择，同时补充来源状态说明。


## 开发命令

```powershell
npm install
npm test
npm run typecheck
npm run build
npm run dev
```

开发服务器不会在缺少桌面桥时伪造用量。需要验收纯前端演示数据时，显式打开：

```text
http://127.0.0.1:4173/?demo=1&state=ready
```

可将 `state` 改为 `loading`、`offline`、`stale`、`error`、`unauthenticated` 或 `unsupported` 检查降级状态。演示页会明确标记数字并非真实用量。

只读连接当前 Codex 账号并输出脱敏字段形状：

```powershell
npm run probe
```

只读扫描本机 rollout，并输出派生汇总：

```powershell
npm run scan
npm run desktop:dev
npm run desktop:build
npm run rust:test
```

## 数据边界

- App Server 用量是账号级状态，但某些字段可能缺失，且协议仍会随 Codex 版本变化。
- 账号额度与账号每日 Token 由应用启动本机 `codex app-server` 后联网读取；子进程沿用 Codex/系统环境中的代理设置。代理关闭且当前网络无法直连 OpenAI 时，账号数据会读取失败，但本机日志索引仍可离线使用。
- 本机 Token 统计只覆盖当前电脑可见的本地记录；它不能代表其他电脑、云端任务或其他共享额度产品的完整明细。
- 额度百分比不能可靠换算为固定 Token 数；耗尽时间只能作为后续的趋势估计，不能作为承诺。
- Codex App Server 当前不返回套餐续费日。额度窗口的重置时间不会被当作套餐续费时间；用户手动填写的日期会单独标明来源。

## Windows 安装包

历史安装包与 `SHA256.txt` 继续保留在 `release` 目录。本轮 v0.9.2 安装包会作为新文件复制到 `release`，不覆盖历史版本；安装包尚未进行商业代码签名。本机构建成功不代替干净 Windows 上的安装、升级、卸载、通知和数据保留验收。

首次启动会建立本机日志索引；历史日志较多时可能需要几十秒，界面会显示当前来源及已处理文件数。后续刷新只读取新增或变化部分。标题栏关闭会隐藏到系统托盘，只有托盘“退出”才结束后台进程；开机启动默认关闭。Windows 原生通知仅在安装后的桌面应用中按系统规则显示，开发模式的呈现不作为发布验收依据。

索引自检使用 SQLite 快速完整性检查并验证应用预期版本。执行重建时，应用会先在自身数据目录的 `index-backups` 下保存带时间戳的派生索引备份，确认备份完成后才移除旧索引并重新扫描；该操作不删除或改写 Codex、Claude Code、OpenCode、WorkBuddy 等来源日志。
