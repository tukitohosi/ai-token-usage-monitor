# 狐仙地灵内置宠物

由项目所有者提供的自定义狐仙地灵图集，与其 Codex 本机使用的完整 v2 图集一致。

- 图集尺寸：1536 × 2288，8 列、11 行，单格 192 × 208。
- 原始资源：`foxian-diling-pet-run/final/foxian-diling-v2.webp`。
- 第 6 行（从 0 计数）为用户指定 `decoded/waiting.png` 的 6 帧透明处理结果。
- 第 1、2 行分别为向右跑、向左跑；第 0 行为待机。

图集由 Rust 编译进应用，首次运行时写入应用自己的宠物目录。无需安装或运行 Codex；丢失或损坏的内置资源会在下次启动时恢复。
